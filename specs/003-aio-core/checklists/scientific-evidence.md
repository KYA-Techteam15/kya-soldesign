# Checklist d'évidence scientifique — AIO Core

**But**: vérifier les exigences de preuve, pas le code.

- [x] Chaque règle `retain` ou `correct` a un identifiant stable dans le registre.
- [x] Chaque règle a au moins une source indépendante versionnée et applicable.
- [x] La validité limitée de IEEE 1562-2021 (PV seul, batterie plomb) est visible.
- [x] La définition de l'énergie, puissance et PSH est appuyée par BIPM/Sandia.
- [x] Le choix du mois de conception reste une donnée tracée, pas une invention du moteur.
- [x] Les rendements, autonomie, DoD et PR ne possèdent aucune valeur par défaut.
- [x] Les formules historiques concurrentes ou aux unités ambiguës sont `unresolved`/`delete`.
- [x] Les comparaisons legacy sont non normatives.
- [x] Chaque règle a une stratégie unitaire, frontière, propriété et golden revue.
- [x] Les sorties de fiabilité, économique, carbone, matériel et sécurité sont écartées.

## Notes

La consultation sous licence du texte IEEE est une exigence de revue si une formule/baseline change; elle n'est pas une dépendance runtime.
