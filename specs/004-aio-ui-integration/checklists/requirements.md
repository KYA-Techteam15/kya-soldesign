# Checklist exigences

- [x] Chaque champ visible a une autorité canonique ou un état indisponible explicite.
- [x] Les trois modes produisent le même contrat journalier AIO.
- [x] Les temps de fonctionnement sont modifiables et persistants.
- [x] Null, zéro et invalide restent distincts.
- [x] Le mois critique et la POA sont sourcés et alignés à l'orientation.
- [x] Aucun résultat futur LPSP/LOLP/SOC/EQP/SAFE/FIN/DOC n'est exposé.
- [x] Une modification technique invalide le résultat antérieur.
- [x] Chaque source météo acceptée possède un fichier réel, un SHA-256 et 8 760 pas valides.
- [x] La POA, les mensuelles, les profils 24 h et `γ` ont formule/source ID, unités et comportement d'échec.
- [x] Téléchargement et import utilisent le même parseur strict sans série simulée.
